# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| RFM | 刷新管理功能 | Page 1-2 | DDR5 中由 controller 触发、帮助缓解 row hammer 的 refresh-management mechanism。 | 是 |
| PAT | 概率 aggressor 跟踪 | Page 1-2 | 以概率方式追踪可能造成 disturbance 的 aggressor rows。 | 是 |
| PRHT | 逐行 hammer 跟踪 | Page 2 | 通过 R/H cells 记录每条 wordline activation count 并触发额外 refresh。 | 是 |
| VBB modulation | 体偏置调制 | Page 3 | 随温度调节 core bias 来改善 retention margin。 | 是 |

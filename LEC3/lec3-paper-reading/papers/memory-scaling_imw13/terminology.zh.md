# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| System-DRAM co-design | 系统-DRAM 协同设计 | Page 1-2 | 重新设计 DRAM 架构、功能和接口，让 controller/processor/software 共同利用内部结构。 | 是 |
| RAIDR | retention-aware intelligent DRAM refresh | Page 2 | 按 retention bins 差异化刷新 rows。 | 是 |
| SALP | subarray-level parallelism | Page 2 | 暴露并利用 DRAM bank 内 subarray 并行性。 | 是 |
| TL-DRAM | tiered-latency DRAM | Page 2 | 把 long bitline 划分为 low/high-latency segments。 | 是 |
| PCM | phase-change memory | Page 3 | 更可缩放、非易失但写延迟/能耗/耐久性存在挑战的 emerging memory。 | 是 |

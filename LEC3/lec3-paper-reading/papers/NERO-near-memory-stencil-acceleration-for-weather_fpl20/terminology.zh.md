# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| Compound stencil | 复合 stencil | Page 1-2 | 天气模型中由多种邻域访问和计算模式组合而成的 stencil kernel。 | 是 |
| CAPI2 | Coherent Accelerator Processor Interface 2 | Page 1-3 | POWER9 与 FPGA coherent accelerator 的连接接口。 | 是 |
| HBM port | HBM 端口 | Page 4 | PE 访问 HBM 带宽的并行入口。 | 是 |
| Processing Element (PE) | 处理单元 | Page 4 | NERO 中执行 stencil 计算的 FPGA 单元。 | 是 |
| COSMO | 小尺度天气模型联盟模型 | Page 1 | 本文的天气预测模型来源。 | 是 |

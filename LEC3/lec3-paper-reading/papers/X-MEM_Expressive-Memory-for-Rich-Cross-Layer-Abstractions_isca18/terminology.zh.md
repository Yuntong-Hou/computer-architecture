# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| Expressive Memory (XMem) | 表达式内存/富语义内存接口 | Page 1 | 把程序高层语义传给系统和硬件的跨层接口。 | 是 |
| Atom | 语义原子 | Page 2-4 | 承载数据属性、访问属性和局部性的虚拟内存区域抽象。 | 是 |
| Atom Management Unit (AMU) | Atom 管理单元 | Page 5 | 维护 AAM/AST 并服务硬件语义查询。 | 是 |
| Semantic gap | 语义鸿沟 | Page 1 | 应用知道的高层数据语义无法被 OS/硬件看到。 | 是 |

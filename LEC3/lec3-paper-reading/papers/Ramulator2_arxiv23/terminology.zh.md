# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| Interface / Implementation | 接口/实现 | Page 2 | Ramulator 2.0 中解耦组件功能与具体行为的核心抽象。 | 是 |
| Controller plugin | 控制器插件 | Page 2 | 不修改 baseline controller 即可接入统计或防御机制。 | 是 |
| DRAM specification syntax | DRAM 规格描述语法 | Page 2-3 | 用简洁字符串和模板函数定义组织、命令、时序和状态。 | 是 |
| Refresh Management (RFM) | 刷新管理 | Page 1-3 | DDR5/LPDDR5/GDDR6/HBM3 等标准中的维护命令之一。 | 是 |
| RowHammer mitigation | RowHammer 缓解机制 | Page 1-4 | PARA/TWiCe/Graphene/Hydra/RRS 等防御插件。 | 是 |

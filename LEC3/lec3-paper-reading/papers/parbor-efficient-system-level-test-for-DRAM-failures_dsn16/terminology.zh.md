# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| PARBOR | Parallel Recursive neighBOR testing | Page 2 | 并行递归定位物理邻居 cell 地址的系统级测试。 | 是 |
| Data-dependent failure | 数据依赖故障 | Page 1 | cell 是否失效依赖邻居 cells 数据模式。 | 是 |
| Strongly coupled cell | 强耦合 cell | Page 2 | 只受一个邻居数据内容影响即可失败的 cell。 | 是 |
| DC-REF | data content-based refresh | Page 2 and Page 11 | 仅当弱 row 中出现 worst-case pattern 时高频刷新。 | 是 |

# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| Set-centric programming | 集合中心编程 | Page 1-2 | 把图挖掘表达为 vertex set operations 的范式。 | 是 |
| SISA | 集合中心 ISA | Page 1 | 用于表达和加速 set operations 的 ISA extensions。 | 是 |
| Dense bitvector (DB) | 稠密位向量 | Page 7-8 | 高 degree vertex sets 的表示，适合 PUM bitwise。 | 是 |
| Sparse array (SA) | 稀疏数组 | Page 7-8 | 低 degree vertex sets 的整数列表表示，适合 PNM。 | 是 |

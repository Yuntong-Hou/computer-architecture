# Terminology

| English Term | 中文翻译 | 出现位置 | 简明解释 | 是否核心术语 |
|---|---|---|---|---|
| Matrix profile | 矩阵轮廓 | Page 1-2 | 每个 subsequence 与最相似 subsequence 的距离数组。 | 是 |
| Anytime algorithm | 可中断算法 | Page 1 | 随时停止也能返回当前有效近似结果的算法。 | 是 |
| Diagonal scheduling | 对角线调度 | Page 5 | 按 distance matrix 对角线划分工作，降低同步并保持算法性质。 | 是 |
| High Bandwidth Memory (HBM) | 高带宽内存 | Page 1-2 | 3D-stacked memory，为 near-data accelerator 提供高带宽。 | 是 |
| Processing Unit (PU) | 处理单元 | Page 4 | NATSA 中计算 matrix profile 的专用近存单元。 | 是 |
